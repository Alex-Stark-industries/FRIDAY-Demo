Get started in minutes

Three steps to talking with Friday

Install Ollama

Install the free local AI engine from ollama.com, then pull the model once: ollama pull qwen2.5:3b

Download Friday

Grab Friday-Voice-Agent-Setup.exe from the releases page. The installer is per-user — no admin rights needed.

Run & talk

Launch Friday from the Start menu. Type in the box, or open voice mode and hold Space to speak.
